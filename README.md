# Sudoku Game

This is a Sudoku game developed using Java as a summative project. The game generates a unique Sudoku board with every run, using a custom algorithm designed to ensure that all Sudoku rules are adhered to. 

## Features

- **Unique Board Generation:** Each run of the program creates a new, valid Sudoku board, ensuring endless replayability.
- **Custom Algorithm:** The Sudoku board is generated using a self-made algorithm that guarantees no Sudoku rules are broken.
- **Playable:** Users can play the game, filling in the grid while the game checks for rule violations.

## Technologies Used

- **Java**: Core development language for building game logic and user interface.

## How It Works

The Sudoku game uses a backtracking algorithm to generate the grid, ensuring that every number is placed according to Sudoku's rules (i.e., no repeated numbers in any row, column, or 3x3 subgrid). Once a valid board is created, the player can begin solving the puzzle.
